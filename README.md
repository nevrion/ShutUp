# Antifaschiste Aktion Azeroth

WoW-Addon für WoW Forever (Interface 16001). Befehl `/aaa`. Setzt Mitglieder der Gilden "Alternative für Durotar" und "Alternative für Azeroth" automatisch auf Ignore. Weitere Gilden: `/aaa gilde + Name`.

Installation: Ordner `AntifaAktionAzeroth` in den AddOns-Ordner des Spiels kopieren.
